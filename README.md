# ESP32/ESP8266 MicroPython Projects

This repository contains my MicroPython practice programs developed while learning ESP32 and ESP8266 programming using the Thonny IDE.

The programs cover GPIO control, LED blinking, timers, UART communication, DHT11 and LM35 sensors, touch sensing, SD card interfacing, and basic web server implementation. These projects helped me understand embedded systems programming, hardware interfacing, and IoT application development.

## Topics Covered

- LED Control
- LED Blinking
- Variable LED Blink
- LED Counter
- DHT11 Temperature & Humidity Sensor
- LM35 Temperature Sensor
- UART Communication
- ESP8266 UART Communication
- Timer Programming
- Touch Sensor
- SD Card Interface
- REPL over SD Card
- ESP32 Web Server
- Basic Messaging Examples

## Technologies Used

- MicroPython
- ESP32
- ESP8266
- Thonny IDE

## Repository Structure

- `blinkled.py` – LED blinking example
- `led.py` – Basic LED control
- `count.py` – Counter example
- `count_led.py` – LED counter
- `dht11.py` – DHT11 sensor interface
- `lm35.py` – LM35 sensor interface
- `uart.py` – UART communication
- `uart_esp8266.py` – ESP8266 UART example
- `timer.py` – Timer programming
- `touch_sense.py` – Touch sensor example
- `sdcard.py` – SD card interface
- `interface_of_sdcard.py` – SD card integration
- `repl_codefor_sdcard.py` – REPL using SD card
- `server_esp.py` – ESP32 web server
- `messaging.py` – Communication example
- `variablebl_blink.py` – Variable delay LED blinking

## Learning Outcome

Through these projects, I gained practical experience in MicroPython programming, embedded systems, sensor interfacing, communication protocols, storage devices, and IoT application development using ESP32 and ESP8266.
